**a[ssistan]t · a[rchivis]t · a[rchitec]t · a[utopilo]t · a[utoagen]t**

AI portfolio by [Leonardo Cardoso](https://github.com/leonardocardoso). Five pillars covering the categories that agent work tends to land in.

→ [a7t.ai](https://a7t.ai) for project deep dives, articles, and the full picture.

### The five pillars

- **assistant** Tools you talk to that take action.
- **archivist** Memory you can trust and recall.
- **architect** Infrastructure for agents and pipelines.
- **autopilot** Routines that hold the line without you.
- **autoagent** Agents that plan, act, and report back.

### Open source

- **[`chat`](https://github.com/a7t-ai/chat)** Self-hosted AI chat for everyone in your house. Your local models, passkey sign-in, no cloud.
- **[`jano`](https://github.com/a7t-ai/jano)** Local-first LLM router and queue. Two models, one GPU, zero cloud.
- **[`slipway`](https://github.com/a7t-ai/slipway)** Self-publishing toolkit for iOS apps. Turns a vanilla Xcode project into one that ships releases on its own.

### Other projects

- **[Three-Body Agent](https://a7t.ai/projects/three-body-agent/)** Autonomous coding pipeline. Picks issues from a GitHub project board, implements them via Claude Code, fixes its own CI failures, merges green PRs.
- **[Poirot](https://poirot.fyi)** Native macOS companion for investigating Claude Code sessions.
